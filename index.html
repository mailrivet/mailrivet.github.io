mailrivet

mailrivet is a local command-line tool that lets an AI agent running on your own computer sweep your Gmail and Outlook.com inboxes, read threads, and create reply drafts for you to review.

  • It runs entirely on your machine. There is no mailrivet server.
  • It never sends, deletes or moves email. It requests read access and, if you allow it, permission to create drafts. It never requests send permission.
  • Sign-in tokens are kept in your operating system's keychain.

Each user connects mailrivet through their own Google Cloud project or Microsoft Entra app registration.
